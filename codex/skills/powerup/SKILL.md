# Powerup

Announce powerup mode and the main agent's authorship. Read the sibling
`consult/SKILL.md`, `design-doc/SKILL.md`, `delivery/SKILL.md`, and
`evolve/SKILL.md` in full. Their conditional references to the other active modes
now apply. This composition grants no new external-action or installation rights.

Write the code, tests, migrations, and design yourself. Advisors supply judgment;
attackers challenge design decisions; grounders check owed propositions; reviewers
inspect the resulting change. Do not recreate an executor tier or the retired
orchestrate workflow.

Preserve each loop's convergence rule. Design-doc owns design closure. Delivery
owns code review and its medium effort ceiling. A blocker changes a design
decision or code semantics. Record and fix editorial findings without starting
another expensive round solely because a reviewer returned something.

Keep one advisor per problem and one reviewer per change when actual continuation
is available. Follow up on the same agent ID with the changes and what they might
break. Give a fresh replacement the full review aperture; do not claim it shares
its predecessor's memory. Grounder/attacker reuse follows the evidence runner's
real lifecycle and distinct-workspace accounting. Their context isolation must
not be replaced with parent-history inheritance.

Pin effort for each agent's lifetime. Start bounded checking/summarization low
when suitable; investigative evidence passes remain medium. Consult owns advisor
tiering. Do not import Claude model aliases, cache lifetimes, pricing ratios,
or performance measurements as Codex guarantees. Never send keep-alive pings.

At a design or implementation-slice boundary, compare the remaining work with
the context a fresh session would need. No measured context value means no
invented break-even calculation. Make decisions, findings, exact file locations,
review state, and unresolved obligations durable before handing off.

A handoff must preserve the current item and phase, active skills, authority,
source state including uncommitted/untracked files, evidence, and the next files
to read. It does not authorize commit/push merely to make the tree clean. Use the controller continuation adapter when its lonic_queue tools are present.
Read [the powerup runtime reference](references/runtime.md) for its launch contract.
If automatic phase changes are requested outside a controller session, resolve the
parameters and help the user start the controller in a terminal. Until then,
provide a ready-to-paste `$powerup` prompt. An ordinary chat cannot replace itself.

Bare powerup ends when its assigned item ends. It never chooses the next queue
item. Queue traversal belongs to queue-run/powerup-auto. Auto-compaction is not a
fresh-session handoff. A requested context threshold also does not mean weekly
usage: keep those measurements separate.

The test-output filter is optional and requires explicit activation. Preserve
test exit status, full logs, and the normal permission checks for the executed
command. Missing filter support does not justify skipping tests or hiding output.

## Explicit B1 managed selection

Only when the operator explicitly selects `--managed`, use [the managed host contract](../../runtime/managed-cli.md). Require `--queue-kind file`, an explicit timeout and prior interactive account enrollment. Do not silently switch an ordinary invocation to this path or fall back after managed refusal. No enabled native hook is allowed, including lonic's own test filter. A clean `incomplete` result preserves context and does not grant a third author. This path is experimental. Narrow native observations cover enrollment, admission, handoff, cancellation, Node-substitute forced closure and ordinary reconcile; file work is unverified. Command execution is not authorized, supported or observed. All existing rules above remain the ordinary workflow.
